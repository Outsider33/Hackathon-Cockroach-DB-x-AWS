The memory that says what it is missing

An engineering agent keeps its beliefs in CockroachDB, with the interval over which each one was held and the evidence that ended it. Nothing is overwritten. What it does not know is stored at the same rank as what it does, so the question “can this two-hour computation run yet” is a join rather than an opinion.

Now tell it something

The agent reads a claim, finds the belief it touches, and answers one of three ways: it revises, it says the memory already holds that, or it refuses and says what it would need. A claim declares its parts — <subject> is <value> because <evidence> — because inferring them out of prose is how this memory once got four facts wrong in a single pass. What you write here expires within a day; what the engineer wrote does not.
